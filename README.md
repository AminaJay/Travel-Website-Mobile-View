# Travel-Website-Mobile-Desktop-View

## Project Description
This is a landing page for a travel agency that helps users find their ideal travel destinations. The site highlights key features such as a wide variety of destinations, a team of best guides, special ticket offers, and 24/7 support. The goal is to make travel memorable for customers.

## Installation
This is a static website. To view it, simply open the **`index.html`** file in your web browser. There are no additional dependencies or setup required.

***

## Usage
The Travel Website showcases various travel destinations and features of the travel agency. Users can browse the destination cards, learn about the company's offerings, and watch a trip documentation video.
